# Brand assets

`assets` preserves 22 SVG blocks from the supplied kit and play-once attachment. Original pasted documents are under `source`. The manifest records each variant's source and ordinal.

The `once-` prefix identifies play-once assets. Looping variants from the original kit are retained for future selection. Respect reduced-motion preferences when using animations.

The development shell uses only a supplied static icon. No product interface has been designed. Import assets through `@zerocloud/brand/*`.
